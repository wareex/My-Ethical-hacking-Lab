# Penetration Testing Lab Portfolio

## Overview
This repository documents hands-on penetration testing exercises conducted in fully
isolated, self-owned lab environments for educational and defensive security purposes.

All assessments were performed against intentionally vulnerable systems or services
configured specifically for testing. No production systems or third-party infrastructure
were targeted.

The focus of this portfolio is on **methodology, validation, evidence collection, and
defensive remediation**, rather than offensive exploitation alone.

---

## Lab Environments
- **Kali Linux** – Attacking and assessment workstation
- **Ubuntu Server** – Self-configured services for security testing
- **Windows 8.1** – Client system for functional validation
- **Metasploitable 2** – Intentionally vulnerable training virtual machine

All systems were deployed using VMware Workstation and isolated using NAT or Host-Only
networking.

---

## Skills Demonstrated
- Network service enumeration and validation
- Authentication and access control testing
- Network traffic analysis
- Availability and denial-of-service impact testing
- Misconfiguration discovery
- Controlled exploitation using Metasploit
- Log analysis and evidence correlation
- Risk assessment and mitigation planning

---

## Methodology
Assessments follow principles aligned with:
- PTES (Penetration Testing Execution Standard)
- OWASP Testing Guide
- Defensive security best practices

Each service assessment includes:
1. Scope and authorization
2. Objective
3. Methodology
4. Findings
5. Evidence
6. Impact analysis
7. Mitigation recommendations
